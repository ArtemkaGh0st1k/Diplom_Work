# theory/ — теоретические материалы

Сюда складываются материалы по предметной области: книги, статьи, методички,
конспекты лекций, свои заметки (PDF, DOCX, MD, изображения формул и т.д.).

Рекомендуемая раскладка (необязательная):

- `papers/` — научные статьи (гармонические / многопорядковые дифракционные линзы и т.п.)
- `books/` — учебники и главы из них
- `lectures/` — лекции, методички
- `notes/` — свои заметки и выводы

После того как файлы добавлены, попросите Claude: «изучи теорию в папке theory».
Claude прочитает материалы и составит конспект `NOTES.md` — ключевые формулы,
обозначения, допущения и где они используются в коде. Этот конспект читают все
агенты проекта перед работой с физикой.
