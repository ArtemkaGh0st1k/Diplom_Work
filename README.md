# Фокальный сдвиг системы гармонических линз

Магистерская работа: **«Моделирование фокального сдвига системы гармонических
линз в видимом диапазоне методом трассировки лучей»**.

Система состоит из 2–5 гармонических (многопорядковых) дифракционных линз из
BK7. Подбираются высоты микрорельефа h, расстояния между линзами и
распределение оптических сил так, чтобы фокус как можно меньше «гулял» по
длине волны в диапазоне 400–700 нм. Каждый результат считается двумя
способами: параксиально (матрицы ABCD) и трассировкой лучей. Трассировка —
это перенос на Python программы Harmony (C++) научного руководителя.

### Минимальный пример

```python
from data.dataset_helper import DataSetHelper
from optimizers.base import BaseLensOptimizer
from optimizers.tracing import trace_focus_dict
from utils.unit import UnitType

dataset = DataSetHelper.create_dataset(
    count_linse=2, lower_lambda=400, upper_lambda=700,
    focus_0={1: 200, 2: 200}, harmonica={1: 7, 2: 7}, distance={'1-2': 10})
heights = {UnitType.MICROMETER: [7.30, 7.84]}

paraxial = BaseLensOptimizer().lmbd_focus_dict(dataset, heights)   # {λ, м: задний отрезок, м}
traced = trace_focus_dict(dataset, heights, aperture='mean')       # то же, трассировкой

df = max(paraxial.values()) - min(paraxial.values())
print(f'Длина фокального отрезка: {df * 1e3:.3f} мм')
```

## Модель

Подробно — в [theory/NOTES.md](theory/NOTES.md), там же список статей.

**Гармоническая линза.** Радиусы зон заданы гармоникой m, расчётной длиной
волны λ0 и фокусом f0. Высота рельефа H определяет только рабочий порядок
дифракции k на длине волны λ:

    k = round(H · (n(λ) − 1) / λ),      f(λ) = m · λ0 · f0 / (k · λ)

Порядок k всегда целый. Показатель преломления BK7 считается по формуле
Селлмейера (`utils/materials.py`).

**Система.** Матрицы преломления [[1, 0], [−1/f, 1]] и переноса
[[1, d], [0, 1]]. Положение фокуса — задний фокальный отрезок −A/C.

**Критерий.** Длина фокального отрезка Δf — разброс положения фокуса по
спектру. Для сравнения систем с разным фокусом используется Q = Δf / f.

**Трассировка** (`optimizers/tracing`) повторяет C++ программу Harmony: каждая
поверхность — таблица профиля из 100 000 точек, точка пересечения ищется
бисекцией, преломление — по закону Снелла. Есть два режима:
- `cpp` — точно как в оригинале; совпадает с `Harmony.exe` до 10⁻⁶ мм;
- `grating` (по умолчанию) — порядок выбирается с учётом дисперсии, и у оси
  результат совпадает с параксиальной моделью.

## Структура

```
data/                    датасеты по умолчанию, DataSetHelper (создание, экспорт в JSON)
optimizers/
  base.py                BaseLensOptimizer: lmbd_focus_dict - главная целевая функция
  two_lens.py … five_lens.py
                         оптимизаторы для фиксированного числа линз
  two_lens_study.py      исследование 2 линз: расстояние d и соотношение сил
  multi_lens_study.py    то же для 3–5 линз (покоординатный спуск + перебор пар)
  study_plots.py         рисунки по CSV обоих исследований
  tracing/               трассировка лучей (перенос C++ Harmony)
    surface.py           поверхность HarmLens: профиль, бисекция, нормаль, Снелл
    system.py            система поверхностей, фокус по вееру лучей, фокальный сдвиг
    hl_io.py             чтение систем Harmony (.hl, .nnn)
    harmonic_system.py   датасет проекта -> поверхности, trace_focus_dict
  tracing_and_paraxial/optimize_and_trace.py
                         оптимизация 2–4 линз и проверка трассировкой (запускается из main.py)
utils/                   единицы (unit.py), ключи датасета (keys.py), материалы (materials.py)
validators/              проверка датасета и путей
gui/                     интерфейс на tkinter
theory/                  статьи (papers/) и конспект NOTES.md
results/                 отчёты, рисунки, материалы НИР и презентации
main.py                  точка входа: оптимизация + трассировка
```

**Единицы.** В датасете длины волн в нм, фокусы и расстояния в мм, высоты в
мкм (`utils/unit.py`). `lmbd_focus_dict` возвращает значения в метрах. Внутри
`optimizers/tracing` всё в миллиметрах, как в C++ оригинале.

## Известные ограничения

- `main.py` (`optimize_and_trace.py`) перебирает высоты 5–10 мкм. В этом
  диапазоне на λ0 может работать уже не порядок m, и фокус системы уходит от
  заданного. В исследованиях `*_study.py` высоты ограничены полосой порядка m
  (6.89–7.95 мкм при m = 7).
- Апертура при трассировке 10 мм: сферическая аберрация мала, и трассировка
  почти совпадает с параксиальным расчётом.
- В исходной C++ программе таблица `.nnn` индексируется с отбрасыванием
  дробной части (550 нм → n(540 нм)). Порт сохраняет это намеренно.
