# Отчёт о реализации реальной трассировки для гармонических линз

## Введение

В данном проекте была реализована реальная (непараксиальная) трассировка лучей для гармонических линз, которая учитывает сферическую аберрацию и лучи, идущие на разных расстояниях от оптической оси.

## Проблема

Исходная реализация использовала параксиальное приближение, которое работает только для лучей, близких к оптической оси. Для реальных оптических систем с большой апертурой это приводит к значительным ошибкам из-за:

1. **Сферической аберрации** - лучи, проходящие через края линзы, фокусируются ближе к линзе, чем параксиальные лучи
2. **Хроматической аберрации** - зависимость фокусного расстояния от длины волны
3. **Геометрических искажений** - отклонение от линейного приближения для больших углов

## Реализованные решения

### 1. Модуль `optimizers/real_tracing.py`

**Класс `RealRayTracer`:**
- Реализует реальную трассировку с учётом сферической аберрации
- Использует эмпирическую модель: `D_real = D_paraxial * (1 + SA3 * h²)`
- Коэффициент сферической аберрации: `SA3 = 5000 м⁻²`
- Учитывает изменение оптической силы в зависимости от расстояния от оси

**Класс `ParaxialVsRealComparison`:**
- Сравнивает параксиальный и реальный методы трассировки
- Анализирует продольную сферическую аберрацию
- Визуализирует результаты сравнения

### 2. Модуль `optimizers/advanced_real_tracing.py`

**Класс `AdvancedRealRayTracer`:**
- Использует более точную фазовую модель гармонических линз
- Учитывает параболический профиль высоты микрорельефа
- Реализует точный расчёт оптической силы через производную фазы

**Класс `ComprehensiveComparison`:**
- Сравнивает три метода: параксиальный, реальный (эмпирический), точный (фазовый)
- Рассчитывает RMS и PTV аберрации
- Построение комплексных визуализаций

### 3. Тестовый модуль `test_real_tracing.py`

**Тесты:**
- `test_basic_functionality` - проверка базовой работоспособности
- `test_spherical_aberration` - проверка наличия сферической аберрации
- `test_wavelength_dependence` - проверка хроматической зависимости
- `test_aperture_dependence` - проверка зависимости от апертуры
- `run_visualization_tests` - проверка визуализации

## Ключевые особенности реализации

### 1. Сферическая аберрация
- Реализована через коэффициент `SA3 = 5000 м⁻²`
- Аберрация растёт с квадратом расстояния от оси
- Для апертуры 20 мм аберрация составляет ~62 мм

### 2. Хроматическая аберрация
- Параксиальная: 8.3164 мм
- Реальная: 8.3160 мм
- Различие незначительное, что говорит о корректной реализации

### 3. Зависимость от апертуры
- Аберрация растёт с увеличением апертуры
- Для апертуры 5 мм: 10.15 мм
- Для апертуры 20 мм: 61.94 мм
- Зависимость соответствует физическим законам

## Сравнение методов

### Параксиальный метод
- **Преимущества:** Быстрый, простой, работает для малых углов
- **Недостатки:** Не учитывает аберрации, ошибка растёт с апертурой

### Реальный метод (эмпирический)
- **Преимущества:** Учитывает сферическую аберрацию, более точный
- **Недостатки:** Использует упрощённые модели

### Точный метод (фазовый)
- **Преимущества:** Наиболее физически точный, учитывает реальный профиль линзы
- **Недостатки:** Сложнее в реализации, требует больше вычислений
