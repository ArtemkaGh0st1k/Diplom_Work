# НИР, 4 семестр: нейросеть «параметры системы → ФРТ»

Задача (от научного руководителя): обучить нейросеть, которая по параметрам
системы гармонических линз предсказывает функцию рассеяния точки (ФРТ), и
подбирать оптимальные параметры системы по этой ФРТ. Датасет — несколько тысяч
оптимизированных систем. Образец подхода — диссертация Д. А. Рымова
(`theory/papers/Рымов_Д_А_Текст_диссертации.pdf`): там сеть с встроенной
физической моделью предсказывает изображение, а качество оценивается по КК и ИСС.

Код лежит в `nn/`, результаты — в этой папке.

## 1. Что считается ФРТ (`nn/psf.py`)

Используется полихроматическая геометрическая ФРТ, полученная реальной
трассировкой лучей (порт программы Harmony, `optimizers/tracing`).

**Параметры расчёта**
- Длины волн: 400–700 нм с шагом 10 нм (31 длина волны), веса одинаковые.
- Лучи: меридиональный веер из 96 лучей на апертуре диаметром 10 мм. Вес луча пропорционален ρ, чтобы учесть площадь кольца зрачка.

**Порядок расчёта**
1. Плоскость наилучшей фокусировки z\* находится аналитически — как минимум
   среднего квадрата радиуса пятна по всем лучам и длинам волн.
2. Радиальное распределение энергии в плоскости z\* переводится в изображение
   64 × 64 пикселя на поле ±0,5 мм (пиксель 15,6 мкм) интегрированием по субпикселям.
3. Энергия сохраняется: в среднем в кадр попадает 99,96 % энергии.

Расчёт одной системы занимает 0,02–0,1 с.

## 2. Датасет (`nn/dataset.py`)

| | |
|---|---|
| Систем всего | **40 000** (20 000 конфигураций × 2 варианта высот) |
| Число линз N | 2–5, примерно поровну (9824 / 10400 / 10046 / 9730) |
| Расстояние d | 0–60 мм (в 15 % случаев d = 0) |
| Силы линз | одинаковые (12 246); разбиение Φ = const по Дирихле (25 160); с одной рассеивающей линзой (2594) |
| Высоты H | полоса порядка m = 7: 6,89–7,95 мкм |
| Варианты | **оптимизированный** — минимум длины фокального отрезка, покоординатный спуск из 4 стартов; **случайный** — высоты из той же полосы |

Медианный rms-радиус пятна: 61 мкм у оптимизированных систем и 83 мкм у случайных.
237 систем с пятном, выходящим за кадр (энергия в кадре < 95 %), исключены из обучения.
Сводки по системам (без изображений): `psf_dataset_summary.csv` и
`psf_dataset_2_summary.csv`. Сами `.npz` (45 МБ) лежат в `nn/data/` и исключены из git.

Почему в датасете есть и случайные варианты: чтобы искать оптимум через сеть,
она должна видеть не только хорошие, но и плохие системы.

Генерация на 6 процессах:

```bash
python -m nn.dataset --configs 4000 --workers 6 --seed 4 --name psf_dataset
```

```bash
python -m nn.dataset --configs 16000 --workers 6 --seed 5 --name psf_dataset_2
```

## 3. Архитектуры (`nn/model.py`)

**Вход:**
- one-hot числа линз;
- d / 50 мм;
- для каждой из 5 позиций: сила 100 мм / f, маска наличия линзы, нормированная высота;
- фазовые признаки cos(2πα) и sin(2πα), где α = H(n(λ) − 1)/λ, на 7 длинах волн.

Фазовые признаки нужны потому, что рабочий порядок k = round(α), и без них ФРТ
зависит от высоты ступенчато.

| Сеть | Устройство | Параметров |
|---|---|---|
| `physics` | MLP 4 × 256 → softmax по 256 радиальным кольцам (+ 1 выход «за кадром») → фиксированный линейный оператор «кольца → изображение» | 287 тыс. |
| `physics_plain` | то же, без фазовых признаков | 269 тыс. |
| `conv` | MLP → 128 × 8 × 8 → 3 блока транспонированной свёртки → softmax по 64 × 64 пикселям | 2,4 млн |

Сеть `physics` физически-информированная, по аналогии с Рымовым. В её
архитектуру встроены известные свойства системы:
- осевая симметрия;
- неотрицательность энергии и сохранение суммарной энергии.

Оператор рендеринга тот же, что в генераторе ФРТ, расхождение не больше 1e-9.

**Обучение:**
- функция потерь: MSE · 10⁴ + (1 − КК) — потери на основе КК, как у Рымова (ур. 2.2);
- оптимизатор AdamW с шагом 2·10⁻³ и косинусным расписанием, батч 128;
- разбиение 80/10/10 по конфигурациям: оба варианта одной системы всегда попадают в одну часть, утечки нет;
- сохраняется модель с лучшей ошибкой на валидационной выборке;
- только CPU: physics обучается 100 эпох за 11 минут, conv — 40 эпох за 1,8 часа.

```bash
python -m nn.train --model physics --epochs 100
```

## 4. Точность предсказания ФРТ (тестовая выборка, 4227 систем)

|---|---|---|---|---|---|
| `physics` | **0,991** | 0,995 | 0,035 | 10,0 % | 0,927 |
| `physics_plain` | **0,991** | **0,996** | **0,033** | 8,8 % | **0,940** |
| `conv` | 0,990 | 0,995 | 0,034 | **8,5 %** | 0,933 |

Обозначения в таблице:
- **КК** — коэффициент корреляции;
- **ИСС** — индекс структурного сходства, SSIM;
- **ошибка EE50** — средняя абсолютная ошибка доли энергии в круге радиусом 50 мкм;
- **ошибка rms** — средняя относительная ошибка rms-радиуса пятна;
- **ранговая корр. EE50** — насколько правильно сеть упорядочивает системы по качеству; это главное для оптимизации.

На оптимизированных системах точность выше, чем на случайных:

| Сеть | КК, оптимизированные | КК, случайные | Ранговая корр., оптимизированные |
|---|---|---|---|
| `physics` | 0,995 | 0,987 | 0,949 |

Полные метрики — в `metrics_<сеть>.json`.

**Выводы**
- Все три сети воспроизводят ФРТ с КК ≈ 0,99. Это уровень результатов Рымова.
- Встроенная физика (`physics`) даёт ту же точность при числе параметров в 8 раз
  меньше и обучении в 10 раз быстрее, чем свёрточный декодер (`conv`).
- Худшие случаи — сильно дефокусированные широкие пятна (КК ≈ 0,66). Для
  оптимизации они не важны.

Рисунки:

## 5. Подбор параметров по ФРТ через сеть (`nn/inverse.py`)

**Критерий** — максимум EE50, доли энергии ФРТ в круге радиусом 50 мкм.

**Как ищутся высоты**
- Высоты непрерывны внутри полосы m = 7: H = H_min + (H_max − H_min)·sigmoid(u).
- Оптимизация — градиентный подъём (Adam): 256 стартов одновременно, 300 шагов.
  Градиент берётся аналитически через сеть.
- 8 лучших по предсказанию сети различных решений проверяются трассировкой, из них выбирается лучшее.
  Это компенсирует ошибку модели и стоит около 0,5 с.

**Все найденные решения проверяются трассировкой.** С ними сравниваются:
- исходные высоты H = mλ₀/(n − 1);
- оптимум по длине фокального отрезка Δf (параксиальный расчёт);
- для N = 2 — полный перебор высот с трассировкой (сетка 27 × 27, эталон).

Результат для сети `physics`. Значения — EE50 по трассировке.

| Случай | Исходные | Оптимум по Δf | Сеть | Сеть + 8 кандидатов | Перебор |
|---|---|---|---|---|---|
| N=2, одинаковые, d=20 | 0,287 | 0,500 | 0,551 | 0,551 | 0,563 |
| N=2, Φ=const, d=50 | 0,311 | 0,541 | 0,567 | 0,579 | 0,592 |
| N=3, одинаковые, d=20 | 0,297 | 0,540 | 0,672 | **0,728** | — |
| N=3, Φ=const, d=50 | 0,339 | 0,665 | 0,726 | **0,789** | — |
| N=4, одинаковые, d=20 | 0,305 | **0,787** | 0,722 | 0,757 | — |
| N=4, Φ=const, d=50 | 0,373 | 0,805 | 0,830 | **0,870** | — |
| N=5, одинаковые, d=20 | 0,312 | 0,747 | 0,723 | **0,771** | — |
| N=5, Φ=const, d=50 | 0,428 | 0,827 | 0,896 | **0,932** | — |
| **Среднее** | 0,332 | 0,677 | 0,711 | **0,747** | |

Время на один случай (CPU):

| Способ | Время | Масштабируемость |
|---|---|---|
| Оптимум по Δf | 0,02–0,2 с | |
| Сеть | ≈ 6,5 с | не зависит от N |
| Проверка 8 кандидатов трассировкой | ≈ 0,5 с | |
| Полный перебор | 36 с для N = 2 | для N = 5 потребовалось бы 27⁵ ≈ 14 млн трассировок, порядка 3 суток |

**Выводы**
1. Подбор по ФРТ через сеть даёт EE50 больше оптимума по Δf в 7 из 8 случаев.
   В среднем это 0,747 против 0,677, то есть +10 %.
   Минимальная длина фокального отрезка не означает лучшее пятно рассеяния: реальная ФРТ
   учитывает аберрации и распределение энергии по длинам волн, которых нет в
   параксиальном Δf.
2. Для N = 2 решение сети достигает 98 % от эталона полного перебора: 0,551 против 0,563
   и 0,579 против 0,592. Найденные высоты близки к эталону: (7,53; 7,04) против (7,53; 7,09).
3. Проверка нескольких кандидатов трассировкой обязательна. Сеть
   систематически завышает EE50 у своих же оптимумов: оптимизатор находит места,
   где модель ошибается в лучшую сторону. Отбор 8 кандидатов по трассировке
   добавляет в среднем +0,036.
4. Единственный проигрыш — одинаковые линзы, N = 4, d = 20. Там сеть
   сильнее всего переоценивает своё решение (предсказано 0,79, по трассировке 0,72). Как улучшить:
   - дообучать сеть на найденных ею же решениях (активное обучение);
   - использовать решение сети как старт для локального поиска по трассировке.
5. Сеть без фазовых признаков (`physics_plain`) по метрикам на тесте чуть
   лучше, а в подборе хуже: среднее 0,716 против 0,747
   (`inverse_design_physics_plain.csv`). Фазовые признаки делают зависимость от
   высоты гладкой, и градиентный поиск по ним работает лучше.

Запуск:

```bash
python -m nn.inverse --model physics
```

Результаты:
- таблицы `inverse_design_<сеть>.csv`;
- рисунки `figures/inverse_ee50_<сеть>.png` и `figures/inverse_psf_<сеть>.png`.

## 6. Ограничения

- ФРТ геометрическая. Дифракционная ФРТ (интеграл Френеля по зрачку) точнее для
  малых пятен, но в десятки раз дороже для датасета. Это следующий шаг.
- Учитывается только осевая точка. Полевые точки и внеосевая ФРТ не рассматриваются.
- Варьируются только высоты в пределах одного порядка m = 7. Расстояния и фокусы
  подаются на вход как условия, но не оптимизируются. Сеть это позволяет: достаточно
  сделать d и f обучаемыми в `nn_optimize`.
