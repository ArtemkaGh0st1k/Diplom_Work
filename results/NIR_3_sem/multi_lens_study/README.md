# Системы из 3–5 гармонических линз: расстояние и распределение сил

Дата: 28.10.2026. Это продолжение исследования двух линз
([`two_lens_study`](../two_lens_study/README.md)) по тем же направлениям научного руководителя.

Скрипты:
- расчёт: `optimizers/multi_lens_study.py` (около 27 минут на все N);
- рисунки: `optimizers/study_plots.py` (читают CSV, пересчёт не нужен).

## Постановка

Всё как для двух линз:
- BK7, m = 7, λ0 = 550 нм;
- спектр 400–700 нм, шаг 1 нм;
- высоты рельефа в полосе 6.89–7.95 мкм, где на λ0 работает порядок 7;
- критерий: Q = Δf / f, где Δf — разброс заднего фокального отрезка, f —
  фокус системы на λ0.

**Как ищутся высоты.** Полный перебор 107ᴺ невозможен. Поэтому:
- покоординатный спуск по сетке с шагом 0.01 мкм из 48·(N−1) случайных
  стартов;
- 8 лучших решений дополнительно перебираются по парам линз.

**Проверка оптимизатора:**
- для N = 2 и N = 3 он находит тот же минимум, что и полный перебор;
- для N = 4 и 5 запуски с тремя разными seed дают одно и то же решение;
- столбец `starts_hit_best` — сколько из 8 отполированных решений пришли к
  лучшему. Там, где он равен 1, оптимум найден менее уверенно.

**Перепроверка каждого оптимума:**
- через `lmbd_focus_dict`: совпадение до 10⁻³ мм;
- трассировкой (`optimizers/tracing`, D = 10 мм, 10 лучей): расхождение
  не больше 0.01 процентного пункта Q.

## Задача 1. Одинаковые линзы, одинаковое расстояние d

Линзы f0 = 100·N мм, так что при d = 0 фокус системы 100 мм. Значения Q, %
([рисунок 1](figures/1_q_vs_distance.png)):

| d, мм | N = 2 | N = 3 | N = 4 | N = 5 |
|---|---|---|---|---|
| 0 | 9.62 | 7.94 | 6.13 | 5.74 |
| 1 | 9.57 | 7.87 | 6.02 | 5.66 |
| 2 | 9.52 | 7.79 | 5.97 | 5.55 |
| 5 | 9.37 | 7.58 | 5.78 | 5.23 |
| 10 | 9.13 | 7.22 | 5.54 | 4.87 |
| 20 | **8.81** | **6.57** | **5.43** | **4.80** |
| 50 | 8.96 | 6.86 | 5.78 | 5.13 |
| 100 | 9.55 | 8.46 | 8.46 | 8.68 |

**Выигрыш от оптимизации** относительно H = mλ0/(n−1)
([рисунок 2](figures/2_gain_vs_distance.png)):

| N | выигрыш |
|---|---|
| 2 | ~1.9 |
| 3 | ~2.4 |
| 4 | ~3.0 |
| 5 | ~3.3 |

**Наблюдения:**
- Каждая добавленная линза снижает хроматизм. С 3 до 4 линз прирост
  заметный, с 4 до 5 уже меньше: 6.13 → 5.74% при d = 0.
- **С исходными высотами число линз ничего не даёт: Q = 18.4% при любом N.**
  Одинаковые линзы с одинаковым рельефом переключают порядки на одних и
  тех же длинах волн, и их «пилы» складываются. Весь выигрыш от числа линз
  возникает только за счёт подбора разных высот.
- Оптимальное расстояние при любом N около 20 мм. При d = 100 мм хроматизм
  всех систем растёт до 8.5–9.5%.
- **Оптимальные высоты — это набор высот, разнесённых по полосе**
  ([рисунок 3](figures/3_heights_vs_distance.png)). Для N = 5 при d = 10 мм:
  7.00, 7.27, 7.50, 7.70, 7.95 мкм. Высоты отсортированы по величине, потому
  что у одинаковых линз перестановка высот почти не меняет Δf, и привязка
  «высота — номер линзы» неустойчива.

## Задача 2а. d = 0, сила 1/100 мм⁻¹, распределение сил по линзам

Значения Q, % ([рисунок 4](figures/4_power_split_d0.png)):

| распределение | N = 2 | N = 3 | N = 4 | N = 5 |
|---|---|---|---|---|
| поровну | **9.62** | **7.94** | **6.13** | **5.74** |
| по возрастанию 1 : 2 : … : N | — | 7.93 | 6.64 | 5.91 |
| одна сильная (60% силы) | 10.02 | 9.42 | 9.20 | 9.04 |
| одна рассеивающая (−25%) | 14.41 | 10.02 | 7.68 | 7.09 |

**Наблюдения:**
- При d = 0 лучше всего делить силу поровну.
- Сосредоточить силу в одной линзе хуже всего: остальные линзы слишком слабые,
  чтобы скомпенсировать её «пилу». Q почти не зависит от N (9.0–9.4%).
- Рассеивающая линза вплотную не даёт ахромата ни при каком N.

## Задача 2б. Сила системы постоянна, линзы разнесены на d

Силы первых N−1 линз задаются распределением. Силу последней линзы я
подбираю из условия Φ_системы = 1/100 мм⁻¹. Значения Q, %
([рисунок 5](figures/5_power_split_vs_distance.png)):

| N, распределение | d = 0 | 5 | 10 | 20 | 50 |
|---|---|---|---|---|---|
| 3, поровну | 7.94 | 7.72 | 7.49 | 7.01 | 5.53 |
| 3, по возрастанию | 7.93 | 7.73 | 7.52 | 7.11 | 5.95 |
| 3, по убыванию | 7.93 | 7.94 | 7.95 | 7.90 | 7.86 |
| 4, поровну | 6.13 | 5.85 | 5.56 | 5.13 | **4.12** |
| 4, по возрастанию | 6.64 | 6.46 | 6.22 | 5.74 | 4.49 |
| 4, по убыванию | 6.64 | 6.63 | 6.62 | 6.60 | 5.78 |
| 5, поровну | 5.74 | 5.35 | 4.99 | 4.39 | **3.25** |
| 5, по возрастанию | 5.91 | 5.75 | 5.57 | 5.03 | 3.65 |
| 5, по убыванию | 5.91 | 5.69 | 5.57 | 5.47 | 4.00 |

**Наблюдения:**
- При постоянной силе системы разнесение линз уменьшает хроматизм при
  любом N. Для 5 линз Q падает с 5.74% до 3.25%, для 4 линз — с 6.13% до 4.12%.
- Лучше, когда сильные линзы стоят в конце: «поровну» и «по возрастанию»
  лучше, чем «по убыванию». У трёх линз с распределением по убыванию
  разнесение почти не помогает.
- **Оговорка.** Последняя линза подбирается так, чтобы сохранить силу
  системы, и при больших d она становится очень сильной:
  - у 5 линз «поровну» при d = 50 мм её фокус 37 мм;
  - у 4 линз «поровну» — 88 мм;
  - у 5 линз «по убыванию» последняя линза рассеивающая, f = −41.5 мм.

  Такие варианты нужно проверить на реализуемость (зоны, апертура)
  и на большой апертуре трассировкой.

## Ограничения и что дальше

1. **Трассировка пока подтверждает формулы, но не добавляет нового.** При
   D = 10 мм апертура мала. Нужно повторить лучшие варианты при D = 30–50 мм.
2. **Многие оптимальные высоты упираются в границы полосы** (6.89 и
   7.95 мкм). Следующий шаг — сделать параметром и гармонику m каждой линзы.
3. **Варианты с очень сильной последней линзой** (f < 100 мм при d = 50 мм)
   стоит оценить с инженерной стороны, например агентом
   `harmonic-lens-practitioner`.
