# Две гармонические линзы: расстояние и соотношение оптических сил

Дата: 28.10.2026. Скрипт: `optimizers/two_lens_study.py`
(`python -m optimizers.two_lens_study`). Числа взяты из CSV в этой папке.

## Постановка

**Общие параметры:**
- линзы: BK7, гармоника m = 7, λ0 = 550 нм;
- спектр: 400–700 нм (видимый диапазон), шаг 1 нм;
- критерий: Δf — разброс заднего фокального отрезка по λ;
- для сравнения систем с разным фокусом используется Q = Δf / f, где f — фокус
  системы на λ0.

**Как ищутся высоты.** Перебор h1 и h2 по сетке с шагом 0.01 мкм в полосе
6.89–7.95 мкм. В этой полосе на λ0 работает порядок m = 7. Без ограничения
перебор уходит к большим H: растёт рабочий порядок k, и хроматизм падает
(Q ≈ 1/(2k+1), Антонов–Грейсух). Но фокус на λ0 при этом перестаёт быть f0,
и сравнение теряет смысл.

**«Исходные высоты»** — H = mλ0/(n(λ0) − 1) = 7.43 мкм у обеих линз.

**Как проверяется.** Каждый оптимум пересчитывается через
`lmbd_focus_dict` (совпадает до 10⁻⁴ мм) и трассировкой (`optimizers/tracing`,
режим grating):
- D = 10 мм;
- подложка 0.01 мм;
- среднее по вееру из 10 лучей.

Для d = 0 при трассировке линзы стоят вплотную, зазор 0.03 мм.

**Наблюдения:**
- Оптимизация высот уменьшает фокальный отрезок примерно в 2 раза при любом d.
- **Оптимальные высоты разные даже у одинаковых линз** (7.27 и 7.84 мкм).
  Линзы переключают порядки дифракции на разных длинах волн, и их
  «пилообразные» f(λ) частично гасят друг друга.
- При d ≤ 10 мм оптимальные высоты почти не меняются. С d ≈ 20 мм h1 растёт,
  а h2 упирается в верх полосы.
- Минимум Q ≈ 8.8% достигается при d ≈ 20 мм. Дальше хроматизм растёт.
- Решение не единственное: в пределах 1% от минимума лежат от 7 до 92 пар
  высот (столбец `near_opt_count`).

## Задача 2а. d = 0, Φ1 + Φ2 = 1/100 мм⁻¹, варьируется s = Φ1/Φ

| s | f1, мм | f2, мм | h1*, мкм | h2*, мкм | Q опт., % | выигрыш |
|---|---|---|---|---|---|---|
| 0.1 | 1000 | 111 | 7.95 | 7.80 | 12.95 | 1.42 |
| 0.2 | 500 | 125 | 7.95 | 7.67 | 11.49 | 1.60 |
| 0.3 | 333 | 143 | 7.95 | 7.55 | 10.02 | 1.83 |
| 0.4 | 250 | 167 | 7.95 | 7.50 | 10.02 | 1.83 |
| **0.5** | 200 | 200 | 7.27 | 7.84 | **9.62** | 1.91 |
| 0.6–0.9 | | | | | зеркально 0.4–0.1 | |
| 1.25 / 1.5 / 2.0 | 80 / 67 / 50 | −400 / −200 / −100 | 7.95 | 7.95 | 14.41 | 1.28 |

**Наблюдения:**
- При d = 0 результат симметричен относительно s ↔ 1 − s, как и должно быть:
  сила вплотную стоящих линз — сумма Φ1 + Φ2.
- Лучше всего равное деление силы. Чем больше сила сосредоточена в одной
  линзе, тем хуже: второй линзе нечем компенсировать «пилу» первой.
- **Рассеивающая вторая линза (s > 1) не помогает:** Q = 14.4% при любом s.
  У дифракционных линз дисперсия одного знака, и пара вплотную ведёт себя как
  одна линза. Это согласуется с Sweeney (1995): чисто дифракционный ахромат
  возможен только с разнесёнными элементами.

## Задача 2б. Φ1 + Φ2 − dΦ1Φ2 = 1/100 мм⁻¹, варьируются s и d

| s \ d, мм | 0 | 5 | 10 | 20 | 50 |
|---|---|---|---|---|---|
| 0.3 | 10.02 | 9.92 | 9.81 | 9.60 | 8.98 |
| **0.5** | 9.62 | 9.43 | 9.24 | 8.87 | **8.28** |
| 0.7 | 10.02 | 10.02 | 10.02 | 10.00 | 10.01 |
| 1.5 | 14.41 | 14.94 | 15.45 | 16.40 | 17.29 |

В таблице — Q оптимума, %. Трассировка отличается не больше чем на 0.04 п. п.

**Наблюдения:**
- **При постоянной общей силе разнесение линз уменьшает хроматизм**, если
  первая линза не сильнее второй (s ≤ 0.5): Q падает с 9.6% до 8.3%.
- При s = 0.7 (сильная первая линза) расстояние почти не влияет.
- Собирающая + рассеивающая (s = 1.5) с ростом d только хуже.
- Лучший вариант из рассмотренных: s = 0.5, d = 50 мм, Q = 8.28%. Для
  сравнения: задача 1 при d = 0 даёт 9.62%.

## Параксиальный расчёт и трассировка

Во всех 40 вариантах Δf по трассировке отличается от параксиального не
больше чем на 0.04 мм. При D = 10 мм и f ≥ 50 мм апертура мала, и
сферическая аберрация почти не видна. Чтобы трассировка дала новую
информацию, нужна большая апертура: D = 30–50 мм или короче фокус.

## Что можно сделать дальше

1. Увеличить апертуру (D = 30–50 мм) и повторить задачу 1 трассировкой:
   там параксиальный и реальный оптимумы должны разойтись.
2. Добавить в параметры гармонику m каждой линзы, а не только высоту в полосе
   одного порядка. Многие оптимумы упираются в границу полосы (7.95 мкм).
3. Схема Шупмана: рассеивающая линза первой (s < 0) и разнесение d — это
   классический путь к ахромату из дифракционных элементов.
4. Те же задачи для 3 линз.
