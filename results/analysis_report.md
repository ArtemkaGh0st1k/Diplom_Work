# Отчёт по оптимизации и трассировке оптических систем

## Введение

Данный отчёт представляет результаты оптимизации параметров линз (высот микрорельефа) и трассировки лучей для 2-х, 3-х и 4-х линзовых систем с целью минимизации ширины фокального отрезка.

## Методология

### 1. Параксиальный расчёт
Используется матричный метод (ABCD-матрицы) для расчёта фокусных расстояний:
- Матрица преломления: R = [[1, 0], [-D, 1]], где D - оптическая сила
- Матрица переноса: T = [[1, d/n], [0, 1]], где d - расстояние между линзами

### 2. Трассировка лучей
Проводится трассировка лучей через оптическую систему для нахождения положения фокуса:
- Луч запускается параллельно оптической оси на заданной высоте
- Последовательно применяется преломление на каждой линзе и перенос между ними
- Положение фокуса определяется как точка пересечения луча с оптической осью

### 3. Оптимизация
Перебором высот микрорельефа находится комбинация, дающая минимальную ширину фокального отрезка.

Для ускоренного анализа была проведена быстрая демонстрация с уменьшенным диапазоном перебора:

## Выводы

1. **Сравнение методов:** Параксиальный расчёт даёт меньшие значения фокального отрезка по сравнению с трассировкой лучей, что объясняется упрощениями в параксиальном приближении.

2. **Влияние количества линз:** Увеличение количества линз позволяет лучше контролировать хроматические аберрации, но усложняет оптимизацию из-за роста размерности пространства параметров.

3. **Оптимальные параметры:** Найденные оптимальные высоты микрорельефа обеспечивают минимальную ширину фокального отрезка для каждой конфигурации.
